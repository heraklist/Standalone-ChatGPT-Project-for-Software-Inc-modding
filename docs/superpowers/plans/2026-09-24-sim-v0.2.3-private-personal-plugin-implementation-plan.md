# SIM v0.2.3 Private Personal Plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Build, validate, deploy, and certify SIM v0.2.3-preview as a deterministic USER/PRIVATE skills-only OpenAI personal plugin whose exact release works in ChatGPT Web normal Chat, ChatGPT Desktop normal Chat, and Codex.

**Architecture:** production/sim remains the sole handwritten runtime authority. An exact source commit S5 deterministically produces candidate P5 and one-plugin archive B5; Plugin Creator produces private release O5; the exact immutable O5 release is retrieved and independently proven byte-equivalent to P5 before any live behavior test. Local marketplace remains diagnostic only.

**Tech Stack:** Python 3.11, pytest, jsonschema Draft 2020-12, ZIP/sha256 tooling from the Python standard library, GitHub Actions, GitHub exact Git objects, OpenAI Plugin Creator, OpenAI Plugin Management diagnostics.

**Spec:** docs/superpowers/specs/2026-09-24-sim-v0.2.3-private-personal-plugin-architecture-design.md

## Global Constraints

- Canonical SIM target remains Software Inc Beta 1.8.42.
- Canonical plugin identity remains sim; display name remains SIM.
- Canonical version for this implementation is 0.2.3-preview.
- production/sim remains the sole handwritten runtime authority.
- Exactly one public skill is exposed at skills/sim/SKILL.md.
- No MCP server, app dependency, API key, paid service, public publication, Custom GPT, or workspace-plugin substitution is introduced.
- OpenAI production transport is USER scope + PRIVATE discoverability through Plugin Creator.
- ChatGPT Web normal Chat, ChatGPT Desktop normal Chat, and Codex are release-blocking.
- Web normal Chat requires A01-A12, with A06 first.
- Desktop normal Chat requires A01, A03, A06, A09, A10, A12.
- Codex requires A01, A03, A09, A10, A12.
- Local/repository marketplace evidence cannot satisfy personal-plugin production certification.
- Any candidate tree, personal release ID, certification protocol, exact-target digest, surface, or transport change invalidates inherited live evidence.
- No merge, tag, Stable promotion, public publication, branch deletion, or force-push is authorized by this plan.
- Real Plugin Creator create/update is an explicit deployment gate after all static gates are green.

## Review Focus

1. **Release race:** a later personal-plugin update must not cause certification to verify “current” instead of the exact O5 release. Task 7 tests exact plugin_id + release_id binding and current_release_id equality.
2. **Private-directory invisibility:** Plugin Management search may return no SIM entry even when a USER/PRIVATE plugin exists. Task 7 tests that directory absence is diagnostic only and never a certification failure.
3. **Archive representation drift:** ZIP wrapper directories, duplicate entries, permission/timestamp differences, or undeclared files must not produce a different B5 from the same P5. Task 4 pins deterministic archive bytes and exact path closure.
4. **Cross-surface contamination:** a PASS from Work, Desktop, Codex, or local marketplace must never satisfy Web normal Chat. Task 6 pins surface + transport in acceptance context.
5. **Overlay update deletion:** Plugin Creator update cannot delete omitted paths. Task 7 rejects update eligibility when desired P5 requires removing or renaming a path from the current personal release.

- [ ] **Step 3: Implement checksum + Draft 2020-12 validation**

~~~python
def validate_plugin_manifest(
    manifest_path: Path,
    schema_path: Path,
    checksum_path: Path,
) -> list[str]:
    expected = checksum_path.read_text(encoding="utf-8").split()[0]
    actual = hashlib.sha256(schema_path.read_bytes()).hexdigest()
    if actual != expected:
        return ["AGENT_PLUGIN_SCHEMA_CHECKSUM_MISMATCH"]
    schema = json.loads(schema_path.read_text(encoding="utf-8"))
    manifest = json.loads(manifest_path.read_text(encoding="utf-8"))
    validator = jsonschema.Draft202012Validator(schema)
    return [error.message for error in validator.iter_errors(manifest)]
~~~

def verify_personal_release(candidate_root: Path, evidence: dict) -> list[str]:
    errors = []
    if evidence["scope"] != "USER":
        errors.append("PERSONAL_RELEASE_SCOPE_INVALID")
    if evidence["discoverability"] != "PRIVATE":
        errors.append("PERSONAL_RELEASE_DISCOVERABILITY_INVALID")
    if evidence["current_release_id"] != evidence["release_id"]:
        errors.append("PERSONAL_RELEASE_NOT_CURRENT")
    actual = {
        p.relative_to(candidate_root).as_posix(): hashlib.sha256(p.read_bytes()).hexdigest()
        for p in sorted(candidate_root.rglob("*")) if p.is_file()
    }
    if actual != evidence["files"]:
        errors.append("PERSONAL_RELEASE_FILE_HASH_DRIFT")
    return errors
~~~
