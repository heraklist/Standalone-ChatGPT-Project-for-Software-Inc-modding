# Beta 1.7.15 Vanilla Data Corpus

This directory stores derived metadata for the supplied official vanilla Data archive only. The raw ZIP is intentionally excluded from the repository and remains under `.local-sources/` during local verification.

Classification: `VANILLA + OLDER_VANILLA_CORPUS + OLDER_VERSION + VANILLA_OBSERVED`.

An unchanged official wiki edit date does **not** promote this corpus to Beta 1.8.42 authority. Likewise, the presence of a directory or file in a shipped vanilla archive does **not** by itself establish a public mod authoring loader path or supported package layout.

The manifest and per-file hashes are reproducibility evidence for historical fixtures and migration analysis, not exact-target runtime proof.
