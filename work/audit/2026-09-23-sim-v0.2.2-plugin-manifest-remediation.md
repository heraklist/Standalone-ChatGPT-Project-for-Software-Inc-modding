## Root cause

The generated plugin package used custom manifest shapes that did not match the current documented OpenAI Agent Plugins formats.

Old root `plugin.json` used fields including:

- `schema_version`
- `display_name`
- `entrypoint`
- `runtime_skill`
- `public_skill_count`
- `canonical_game_target`

The supported portable root manifest instead requires the Agent Plugins schema declaration and plugin identity. The current OpenAI documentation describes portable skills discovery from the root `skills/` directory.

The old `.codex-plugin/plugin.json` also used custom root fields such as `displayName`, `entrypoint`, `skill`, and `publicSkillCount` instead of the documented compatibility manifest shape.
