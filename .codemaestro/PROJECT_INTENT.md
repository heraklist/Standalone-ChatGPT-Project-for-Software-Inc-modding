# Project Intent

Project: Software Inc Mod Studio
Repository: heraklist/Standalone-ChatGPT-Project-for-Software-Inc-modding
Canonical game target: Software Inc Beta 1.8.42
Delivery case: CodeMaestro DL-001
Delivery date: 2026-09-22

Software Inc Mod Studio is an independent ChatGPT Project for designing, authoring, editing, repairing, researching, and verifying Software Inc mods. The repository is governed by evidence-first, fail-closed rules and is independent from ModForge.

This delivery preserves the current repository architecture and packages the complete source state needed to build, verify, and continue the project. It does not promote the current SIM Preview to Stable and does not override live acceptance evidence.

Primary delivery objective:
- package the exact current SIM remediation baseline;
- preserve all source, tests, schemas, tools, production knowledge, evidence, documentation, and workflows required to build/verify it;
- include generated release artifacts;
- include durable CodeMaestro continuity state;
- exclude secrets and untracked local state.
